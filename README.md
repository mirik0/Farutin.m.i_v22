# Эмулятор оболочки — вариант 22

Консольная программа на Python с виртуальной файловой системой из JSON.
Файлы загружаются в память; команда `rm` не изменяет исходный JSON.
При старте выводятся настройки и содержимое `/motd`, если файл есть.

## Запуск и настройки

Нужен Python 3.9 или новее. Дополнительные библиотеки и сборка не нужны.
Команды выполняются из папки проекта:

```sh
sh run.sh
python3 -m src.main --vfs fixtures/multiple.json --script scripts/startup/stage5.txt
```

- `--vfs` — путь к JSON; по умолчанию `fixtures/multiple.json`.
- `--script` — путь к файлу команд; по умолчанию не используется.
- `--help` — справка по запуску.

Стартовый скрипт содержит по одной команде на строку и останавливается
при первой ошибке. Без `exit` после него начинается интерактивный ввод.
В `fixtures/` есть три примера VFS: `minimal.json`, `multiple.json`, `deep.json`.

## Команды

| Команда | Назначение |
| --- | --- |
| `ls [-a] [путь]` | Список файлов и каталогов; `-a` включает скрытые имена |
| `cd [путь]` | Смена каталога; без пути — переход в `/` |
| `pwd` | Текущий виртуальный путь |
| `date` | Текущая дата и время |
| `uptime` | Длительность сеанса эмулятора |
| `rm [-rRf] путь...` | Удаление файлов; `-r` или `-R` — каталогов с содержимым |
| `conf-dump` | Вывод настроек |
| `exit` | Завершение программы |

`rm -f` игнорирует отсутствующие цели. Корень, текущий каталог и его
родители защищены от удаления. Пути с пробелами заключаются в кавычки.

Пример команд:

```text
cd "my folder"
pwd
ls
cd /
rm -r docs
exit
```

## Код

- `src/main.py` — чтение настроек и запуск программы.
- `src/parser.py` — разбор команд, кавычек, флагов и аргументов.
- `src/vfs.py` — загрузка JSON, поиск путей, список имен и удаление из памяти.
- `src/shell.py` — команды, стартовый скрипт и интерактивный цикл.
